개인정보 처리방침

Serotonin 메모 보드와 그 브라우저 확장 프로그램 "Serotonin 보드 도우미"에 적용됩니다. 최종 수정: 2026-10-11

수집하는 정보

  • 사용자가 입력한 내용: 메모, 인수인계 항목, 일정, 올린 파일, 표시 이름. 소속 부서의 구성원만 볼 수 있으며 다른 부서는 볼 수 없습니다.
  • 임시 계정 정보: 이메일이나 전화번호 없이 만들어지는 익명 임시 계정 번호와 로그인 토큰. 접속 코드는 서버에 암호화 해시로만 보관하고 확장 프로그램에는 저장하지 않습니다.
  • 확장 프로그램 설정: 알림 시각과 켜기/끄기. 이 브라우저에만 저장됩니다.

사용 목적

부서 구성원 사이에서 일정, 인수인계, 메모, 파일을 공유하고 알림을 보여 주기 위해서만 사용합니다. 광고, 분석, 추적, 제3자 판매나 제공은 하지 않습니다.

저장 위치와 전송

데이터는 클라우드 데이터베이스 서비스(Supabase)에 저장되며 보드와 확장 프로그램은 해당 서버와만 통신합니다. 일정 알림을 텔레그램으로 받도록 관리자가 설정한 부서는 일정 제목이 텔레그램으로 전달됩니다. 인수인계 항목은 전달하지 않습니다.

확장 프로그램 권한

  • storage: 임시 계정 로그인과 설정을 이 브라우저에 저장
  • alarms: 10분마다 보드 내용을 확인
  • notifications: 인수인계·일정 알림 표시
  • contextMenus: 선택한 글을 보드에 저장하는 오른쪽 클릭 메뉴. 사용자가 메뉴를 눌렀을 때만 선택한 글과 그 페이지 주소를 보드로 보냅니다.
  • 호스트 권한: 보드의 Supabase 서버 주소 한 곳

보관과 삭제

메모와 일정은 수정 이력과 함께 보관되며 관리자가 부서 단위로 관리합니다. 파일은 최대 7일 뒤 자동 삭제됩니다. 확장 프로그램의 연결 해제를 누르면 이 브라우저의 저장 정보가 모두 지워집니다. 서버의 기록 삭제를 원하면 부서 관리자에게 요청하세요.
