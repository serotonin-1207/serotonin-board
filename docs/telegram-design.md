# 텔레그램 일정 알림 설계 검토

결론: **가능합니다.** 새 유료 서비스는 필요 없고, 이미 쓰는 Supabase 안에서 만들 수 있습니다. 다만 아래 "결정이 필요한 것"이 정해져야 시작할 수 있습니다.

## 구조

```
보드(브라우저) ──일정 저장──▶ Supabase DB
                                │
        pg_cron(정해진 시각) ───▶ Edge Function `telegram-notify`
                                │  (비밀 값: 봇 토큰 / 서버에서만 보관)
                                ▼
                       Telegram Bot API ──▶ 부서 단체방
```

- 봇 토큰은 **Supabase Edge Function의 Secret**에만 저장합니다. 브라우저 코드, GitHub 저장소, 공개 설정 파일에는 들어가지 않습니다. 사용자가 직접 입력합니다.
- 발송은 서버가 하므로 아무도 보드를 열지 않아도 정해진 시각에 나갑니다. (파일 자동 삭제와 같은 방식, 이미 검증됨)
- 부서마다 대화방을 따로 연결하고, 서버가 부서별로만 조회해 보내므로 다른 부서 내용이 섞이지 않습니다.
- 대화방 연결은 일회용 코드를 대화방에 `/link 코드`로 보내면 서버가 `getUpdates`로 확인하는 방식이라 웹훅(공개 수신 주소)이 필요 없습니다.

## 보낼 수 있는 알림

| 종류 | 시점 | 비고 |
|---|---|---|
| 오늘 아침 요약 | 매일 정해진 시각(예: 08:30) | 오늘 근무팀, 오늘 일정, 미완료 인수인계 건수 |
| 내일 예고 | 매일 저녁(예: 18:00) | 내일 일정 (휴가·교육·훈련 등) |
| 새 일정 등록·변경 | 저장 후 몇 분 안에 묶어서 | 한 건마다 보내지 않고 묶어 발송 |
| 인수인계 미완료 | 교대 1시간 전(예: 08:00) | 남은 항목 수와 제목 |

종류와 시각은 부서별로 켜고 끌 수 있게 만듭니다.

## 제한과 위험

- **발송 제한**: 한 대화에 초당 1개, 한 그룹에 분당 20개 이하. 요약 방식이라 문제없습니다.
- **개인정보**: 텔레그램은 기관 밖 서비스입니다. 일정 제목에 이름이나 작전 정보가 들어갈 수 있으므로 **기관 규정 확인이 먼저**입니다. 내용 수준을 3단계로 고를 수 있게 합니다. 전체 제목 / 분류와 건수만 / 근무팀만.
- **단체방 관리**: 방에 있는 사람은 모두 내용을 봅니다. 퇴직·전출자는 방에서 직접 내보내야 합니다. 보드의 접속 코드와는 별개입니다.
- **서버 상태**: Supabase 프로젝트가 일시 중지되면 알림도 멈춥니다. (잠들기 방지 작업이 이미 있음)
- **토큰 유출**: 유출 시 BotFather에서 폐기 후 재발급, Secret만 교체하면 됩니다.

## 구현 단계 (승인 후)

1. DB: 부서별 연결 정보와 알림 설정 표, 일회용 연결 코드, 보낸 기록(중복 발송 방지)
2. Edge Function: 대화방 연결 확인, 요약 만들기(근무팀 계산은 `web/core.js` 규칙과 동일하게), 발송
3. pg_cron: 아침/저녁/교대 전 호출
4. 관리 화면: 연결 버튼, 종류·시각·내용 수준 선택, "시험 메시지 보내기"
5. 시험: 가짜 Telegram 서버로 자동 시험 + 실제 봇으로 사용자와 함께 확인

예상 규모는 파일 자동 삭제 기능(0.8.0)과 비슷하며, 새 버전 0.10.0으로 배포합니다.

## 결정 사항 (2026-10-11)

- 내용: 훈련·교육·연가 같은 단순한 일정이라 **제목을 그대로** 보냅니다.
- 알림 종류: 아침 요약, 저녁 예고, 일정 변경 알림. **인수인계는 알리지 않고** 보드에서만 확인합니다.
- 시각(기본 아침 09:00, 저녁 18:00)과 종류는 부서별로 관리 화면에서 바꿉니다. 대화방은 부서 단체방을 권장합니다.
- 봇은 하나로 충분하며 대화방만 부서별로 나눕니다.
- 구현: 0.10.0 (`supabase/migrations/0.10.0-telegram.sql`, `supabase/functions/telegram-notify`, 관리 화면).
