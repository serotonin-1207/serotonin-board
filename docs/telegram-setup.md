# 텔레그램 연결 준비 안내

보드의 일정을 텔레그램으로 알리려면 **봇(자동 발송 계정) 하나**와 **알림을 받을 대화방**이 필요합니다. 1~3단계는 휴대폰 텔레그램 앱에서, 4~5단계는 컴퓨터의 Supabase 화면에서 합니다.

알리는 내용은 **일정(휴가·교육·훈련 등)** 뿐입니다. 인수인계는 알리지 않습니다.

## 준비물

- 텔레그램 계정(전화번호로 가입, 앱은 무료)
- 알림을 받을 사람들의 텔레그램 계정
- 이 보드의 관리자 코드와 Supabase 로그인

## 1단계. 봇 만들기 (토큰 받기)

1. 텔레그램에서 **@BotFather**를 검색해 대화를 엽니다. 이름 옆에 파란 확인 표시가 있는 공식 계정입니다. 비슷한 이름의 가짜 계정이 있으니 확인 표시를 꼭 보세요.
2. `/newbot`을 보냅니다.
3. 봇의 **표시 이름**을 물으면 알아보기 쉬운 이름을 보냅니다. 예: `일정 알림`
4. **사용자명**(@로 시작하는 주소)을 물으면 영문, 숫자, 밑줄만 써서 5~32자로 보냅니다. **반드시 `bot`으로 끝나야** 하고, 만든 뒤에는 바꿀 수 없습니다. 예: `serotonin_notice_bot`
5. 성공하면 BotFather가 아래와 같은 **토큰**을 보여 줍니다.

   ```
   1234567890:AAExampleExampleExampleExampleExample
   ```

   숫자, 콜론(`:`), 긴 문자열로 이루어져 있습니다.

## 2단계. 토큰을 안전하게 다루기

토큰은 **봇의 비밀번호**입니다. 알고 있는 사람은 누구나 그 봇으로 메시지를 보낼 수 있습니다.

- 채팅, 카카오톡, 이메일, 문서, GitHub 저장소에 **붙여 넣지 마세요.** 개발 도구(Claude)에게도 알려 주지 마세요. 4단계의 Supabase 비밀 값 칸에만 직접 붙여 넣습니다.
- 실수로 노출했다면 바로 **폐기하고 새로 받으세요.** BotFather에서 `/mybots` → 봇 선택 → **API Token** → **Revoke current token**을 누르면 이전 토큰은 못 쓰게 되고 새 토큰이 나옵니다. 그 뒤 4단계의 비밀 값만 새 토큰으로 바꿉니다.

## 3단계. 알림 받을 대화방 만들기

| 방식 | 장점 | 주의 |
|---|---|---|
| **부서 단체방(그룹)** (권장) | 부서원이 한 번에 받고, 새로 들어온 사람도 바로 받습니다. | 방에 있는 모든 사람이 내용을 봅니다. **다른 부서 사람을 초대하지 마세요.** 대화방은 부서마다 따로 만듭니다. |
| **개인 대화** | 본인에게만 옵니다. | 먼저 봇과 대화를 시작(`/start`)해야 합니다. |

단체방 순서입니다.

1. 텔레그램에서 **새 그룹**을 만들고 부서원을 초대합니다. 이름 예: `1부서 일정 알림`
2. 그룹 정보 → **멤버 추가**에서 1단계의 봇(`@serotonin_notice_bot`)을 검색해 추가합니다.
3. 봇은 기본적으로 그룹의 일반 대화를 읽지 않습니다(개인정보 보호 모드). 이 상태가 안전하니 **그대로 두세요.** 연결할 때만 쓰는 `/link@봇이름 코드` 명령은 이 상태에서도 전달됩니다.

> 봇은 하나만 만들어 모든 부서가 함께 써도 됩니다. 대화방만 부서마다 따로 만들면 됩니다. 한 대화방은 한 부서에만 연결됩니다.

## 4단계. 서버에 설치하기 (Supabase 화면, 최초 1회)

개발 쪽에서 코드는 이미 준비했습니다. 아래는 로그인된 본인만 할 수 있는 부분입니다.

1. **데이터베이스 설치**: SQL Editor에 `supabase/migrations/0.10.0-telegram.sql`을 붙여 넣어 실행합니다. (개발 쪽에서 대신 실행해 달라고 하셔도 됩니다.)
2. **함수 배포**: Edge Functions → 새 함수 `telegram-notify`를 만들고 `supabase/functions/telegram-notify/index.ts` 내용을 붙여 넣어 배포합니다. 함수 설정에서 **Verify JWT를 끕니다**(예약 실행이 로그인 없이 부르기 때문). 관리자 동작은 함수 안에서 관리자 로그인을 확인합니다.
3. **토큰 등록**: Edge Functions → **Secrets**(또는 Manage secrets)에서 이름 `TELEGRAM_BOT_TOKEN`, 값은 1단계의 토큰을 **직접 붙여 넣어** 저장합니다.
4. **예약 실행**: SQL Editor에서 `supabase/migrations/0.10.0-cron.sql`을 실행합니다. 5분마다 함수를 불러 보낼 시각이 된 알림을 보냅니다.

## 5단계. 대화방 연결 (보드 화면)

1. 보드 하단 **관리** → 관리자 코드 입력 → **텔레그램 일정 알림**의 **봇 확인**을 누릅니다. “봇 @이름 이(가) 연결되어 있습니다”가 보이면 토큰이 잘 등록된 것입니다.
2. 부서의 **대화방 연결**을 누르면 `/link@봇이름 코드` 문장이 나옵니다. (코드는 15분 동안만 유효하고 한 번만 쓸 수 있습니다.)
3. 그 문장을 3단계의 대화방에 **그대로 보냅니다.** (개인 대화라면 `/link 코드`도 됩니다.)
4. 보드에서 **연결 확인**을 누릅니다. 대화방에 “연결되었습니다”가 오면 성공입니다.
5. **시험 메시지**로 도착하는지 확인하고, **알림 켜기**와 종류·시각을 정해 **저장**합니다.

## 알아 둘 점

- 아침 요약은 기본 09:00입니다. 순환 근무 부서는 09:00에 교대하므로 그 전 시각으로 정하면 전날 팀이 아직 근무 중일 때 도착합니다.
- 켜기 전에 이미 있던 일정은 변경 알림으로 보내지 않습니다. 그날 일정은 아침 요약에 들어갑니다.
- 텔레그램의 발송 제한은 한 그룹에 분당 20개 정도입니다. 알림은 묶어서 보내므로 문제없습니다.
- 대화방에서 봇을 내보내면 다음 발송 때 알림이 자동으로 꺼지고 관리 화면에 오류가 표시됩니다. 봇을 다시 넣고 연결하면 됩니다.
- Supabase 프로젝트가 일시 중지되면 알림도 멈춥니다. (잠들기 방지 작업이 이미 있습니다.)
- 일정 제목이 그대로 텔레그램(기관 밖 서비스)을 지나갑니다. 일정에는 이름과 종류 정도만 쓰도록 안내하세요.
- 이 안내문은 공식 문서(core.telegram.org/bots)를 바탕으로 했습니다. 텔레그램 화면의 메뉴 이름은 앱 버전에 따라 조금 다를 수 있습니다.
