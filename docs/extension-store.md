# 웹 스토어 등록 준비 (Chrome 웹 스토어 / Edge 부가 기능)

확장 프로그램을 스토어에 올리면 개발자 모드 없이 **스토어에서 설치**하고 **자동 업데이트**를 받을 수 있습니다. 계정 만들기와 등록비 결제는 본인이 직접 해야 하고, 아래는 제출에 필요한 것을 정리한 것입니다.

## 먼저 정할 것: 공개 범위

| 방식 | 의미 | 추천 |
|---|---|---|
| **비공개(Private)** | 지정한 이메일 목록이나 조직(Google Workspace 도메인)의 사용자만 설치. 검색에 나오지 않음 | 부서원만 쓰는 지금은 추천 |
| **링크로만 공개(Unlisted)** | 링크를 아는 사람만 설치. 검색에 나오지 않음 | 부서원에게 링크만 전달 |
| **전체 공개** | 누구나 검색해 설치 가능. 접속 코드가 없으면 쓸 수 없지만 심사가 가장 까다로움 | 나중에 |

기관 PC에 설치를 막는 정책이 있을 수 있습니다. 스토어에 올려도 조직이 허용 목록으로 관리하면 설치되지 않으니 먼저 확인하세요.

## 본인이 해야 하는 일

1. **Chrome 웹 스토어 개발자 계정** 등록: 개발자 대시보드(chrome.google.com/webstore/devconsole)에서 Google 계정으로 가입하고 **일회성 등록비(5달러)**를 결제합니다. (결제는 본인이 합니다.)
2. 2단계 인증을 켭니다(필수).
3. 이 폴더의 `serotonin-board-extension-0.1.0.zip`을 **새 항목**으로 올립니다.
4. 아래 "스토어 목록 문구"와 스크린샷을 입력하고 **심사 제출**합니다. 심사는 보통 며칠 걸립니다.
5. Edge 부가 기능(Partner Center, 무료)에도 같은 zip을 올릴 수 있습니다.

## 준비된 것

- 패키지: `npm run build:extension`으로 만든 `serotonin-board-extension-<버전>.zip` (manifest v3, 권한 최소)
- 개인정보 처리방침 주소: `https://serotonin-1207.github.io/serotonin-board/privacy.html` (보드 배포 시 함께 올라갑니다)
- 아이콘 128×128: zip 안 `icons/icon128.png`

## 스토어 목록 문구 (붙여 넣기용)

**이름**: Serotonin 보드 도우미

**한 줄 설명(132자 이내)**: 부서 보드의 오늘 근무팀, 일정, 인수인계를 도구 막대에서 확인하고 알림을 받습니다.

**자세한 설명**:
Serotonin 메모 보드(부서별 근무 달력·인수인계·메모 공유 보드)를 쓰는 부서원을 위한 도우미입니다. 접속 코드는 부서 관리자에게 받아야 사용할 수 있습니다.
- 도구 막대 아이콘에 오늘 근무팀 표시
- 오늘·내일·이후 2주 일정과 미완료 인수인계 보기
- 교대 전 미완료 인수인계, 오늘 일정 알림
- 웹페이지에서 선택한 글을 오른쪽 클릭으로 인수인계 또는 메모에 저장

**카테고리**: 생산성 / **언어**: 한국어

## 심사에서 묻는 항목 (답변 초안)

- **단일 목적**: 부서 보드의 근무·일정·인수인계 정보를 보여 주고 알림과 빠른 입력을 제공한다.
- **storage**: 임시 계정 로그인과 알림 설정을 저장. **alarms**: 10분마다 보드를 확인. **notifications**: 인수인계·일정 알림 표시. **contextMenus**: 선택한 글을 보드에 저장하는 메뉴.
- **호스트 권한**: 보드 데이터가 있는 Supabase 서버 한 곳(`https://uszgkfwucpshubsrokhy.supabase.co`).
- **원격 코드**: 사용하지 않음(모든 코드가 패키지에 포함).
- **데이터 사용 공개**: 개인 식별 정보 수집 없음, 사용자 입력 콘텐츠(사용자가 직접 입력한 메모·표시 이름)만 보드 서버로 전송, 판매·광고·무관한 목적 사용 없음.

## 스크린샷 (1280×800 또는 640×400)

팝업은 360px로 작으므로 보드 화면과 함께 찍은 이미지를 권장합니다. 실제 업무 정보가 아닌 **시험용 데이터**로 찍으세요. 개발 쪽에서 시험 부서로 찍어 드릴 수 있습니다.

## 업데이트

`extension/manifest.json`의 `version`을 올리고 다시 빌드한 zip을 같은 항목에 올리면 됩니다(심사 후 자동 배포).
