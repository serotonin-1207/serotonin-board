# 브라우저 확장 프로그램 사용 안내 (Serotonin 보드 도우미 0.2.0)

Chrome이나 Edge의 도구 막대에서 부서 보드의 **오늘 근무팀, 일정, 인수인계**를 바로 보고 알림을 받는 확장 프로그램입니다. 보드와 같은 서버와 같은 부서 접속 코드를 씁니다.

## 할 수 있는 일

- **오늘 근무팀 배지**: 아이콘 위에 오늘 근무팀(1·2·3)이 숫자로 보입니다. 팀 색은 보드 달력과 같습니다. 순환 근무가 아닌 부서는 미완료 인수인계 건수를 보여 줍니다. 근무일은 09:00에 바뀝니다.
- **팝업**: 아이콘을 누르면 오늘·내일·이후 2주 일정과 미완료 인수인계가 나옵니다. 아래 입력칸에서 인수인계를 바로 추가할 수 있고(`@이름 펌프 점검`처럼 쓰면 담당자 지정), **보드 열기**로 보드를 엽니다.
- **데스크톱 알림**: 10분마다 확인해 교대 전(순환 부서 08:00, 내근 부서 16:00) 미완료 인수인계가 있으면 알려 줍니다. **오늘 일정 알림**도 켤 수 있습니다(기본 꺼짐). 알림은 하루 한 번, 정한 시각 뒤 2시간 안에 나옵니다. 시각은 팝업의 **알림 설정**에서 바꿉니다.
- **인수인계 체크(0.2.0)**: 목록의 체크 칸을 누르면 보드에서 체크한 것과 똑같이 완료로 기록됩니다.
- **옆에 띄우기(0.2.0)**: 팝업의 **옆에 띄우기**를 누르면 브라우저 오른쪽 사이드 패널에 열립니다. 다른 화면을 보면서 계속 열어 둘 수 있고, 미완료 인수인계를 50건까지 보여 줍니다.
- **파일 보내기(0.2.0)**: 사이드 패널에 파일을 끌어다 놓거나 눌러서 고르면 부서 파일함(보드의 “파일”)으로 보냅니다. 보관 기간은 1시간~7일, 파일 하나 50MB까지입니다. 팝업은 다른 곳을 누르면 닫히므로 끌어다 놓기는 사이드 패널에서 하세요.
- **빠른 입력**: 웹페이지에서 글을 선택하고 오른쪽 클릭 → **인수인계에 추가**(줄마다 항목 하나, 최대 10줄) 또는 **보드에 메모로 저장**(첫 줄이 제목, 출처 주소가 같이 저장됨).

## 설치 (개발자 모드, 최초 1회)

1. 개발 PC에서 `npm run build:extension`을 실행하면 `dist-extension/` 폴더와 `serotonin-board-extension-<버전>.zip`이 만들어집니다.
2. Chrome 주소창에 `chrome://extensions`(Edge는 `edge://extensions`)를 열고 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `dist-extension` 폴더를 고릅니다. (zip을 받았다면 먼저 새 폴더에 풉니다.)
4. 도구 막대의 퍼즐 아이콘에서 **Serotonin 보드 도우미**를 고정합니다.
5. 아이콘을 누르고 **접속 코드**와 **표시 이름**을 입력해 연결합니다.

## 개인정보와 보안

- **접속 코드는 저장하지 않습니다.** 처음 연결할 때 서버가 확인하고, 이 브라우저는 서버에 임시 계정으로 등록됩니다. 확장 프로그램에는 임시 계정의 로그인 정보와 알림 설정만 저장됩니다.
- 통신 대상은 보드의 Supabase 서버 한 곳뿐입니다. 광고·분석 서비스는 없습니다.
- 선택한 글을 저장할 때만 그 글과 페이지 주소를 보드로 보냅니다. 페이지 내용을 몰래 읽지 않습니다(권한이 없습니다).
- **연결 해제**를 누르면 이 브라우저의 저장 정보가 모두 지워집니다. 서버에 남은 임시 계정은 관리자 화면의 가입자 목록에서 제거할 수 있습니다.
- 같은 사람이 보드(웹)와 확장 프로그램을 함께 쓰면 가입자 목록에 두 번 나옵니다. 표시 이름을 같게 하면 구분하기 쉽습니다.

## 문제 해결

- "접속 코드를 입력해 주세요"가 다시 뜨면 브라우저 저장소가 지워진 것입니다. 코드를 다시 입력하면 됩니다.
- 알림이 안 나오면 Windows 설정의 알림에서 Chrome(또는 Edge) 알림이 켜져 있는지, 집중 지원이 꺼져 있는지 확인하세요.
- 배지가 비어 있으면 아직 연결 전이거나(아이콘 제목에 안내가 나옵니다) 순환 근무가 아닌 부서에서 미완료 인수인계가 0건인 경우입니다.
